# Zomboid Mod Manager documentation

Buyer documentation for Zomboid Mod Manager, a Pterodactyl 2.0 extension for Project Zomboid servers.
Read it at https://dawidkulpa.github.io/zomboid-mod-manager-docs/.

This repository holds documentation only. The pages are generated from the extension's private source
repository with `scripts/publish-docs.py`; `_config.yml`, `index.md` and `support.md` are edited here.
