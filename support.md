# Support

- **BuiltByBit**: message the author of Zomboid Mod Manager.
- **Discord**: direct message to **buggy121**.

## Include

- Extension version (`php artisan p:extension:list`), panel and Wings versions.
- What you did, what you expected, what happened, with a screenshot or the error message.
- For a failed apply: the step and time, from the progress view or **History**.

Never send your Steam Web API key, the panel's `.env` or `APP_KEY`, Wings tokens or passwords.

## Common issues

| Problem | See |
| --- | --- |
| No **Mods** tab on a server | [Which servers get the Mods page](installation.md#which-servers-get-the-mods-page) |
| An apply never finishes | [Requirements](installation.md#requirements): queue worker and scheduler |
| Workshop search says the key is missing or refused | [Steam Web API key](configuration.md#steam-web-api-key) |
